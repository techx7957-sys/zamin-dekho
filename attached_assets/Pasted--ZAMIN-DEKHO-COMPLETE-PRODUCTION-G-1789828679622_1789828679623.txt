- idempotent initialization

Every initialization function must be safe against accidental double calls.

Example concept:

→ if already initialized, do not initialize again.

cleanup()
→ if already cleaned, do not cleanup again.

→ if already connecting/connected, do not create another connection.

publish()
→ if already publishing, do not publish again.
